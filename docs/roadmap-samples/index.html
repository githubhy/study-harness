What changed in all three

  • Nothing collapses. The current page has 21 <details> panels; these have none.
  • One canonical order per page. The old page listed the same fifteen threads three times in three orders — logic table, alphabetical grid, coverage table — with no signal which was primary.
  • The toy→question mapping travels with each thread instead of sitting in a separate table you had to hold in your head.
  • Thread B is now marked as waiting on note 2.0. The old page tagged it “source only” while its task requires reconciling against the baseline capture — that's what made the count read 15 = 2 + 13 in one place and 12 + 3 in another. It's 12 source-only and 3 evidence-dependent.
